# David Wantangwa — Frontend Course Application

## Open in Visual Studio Code
1. Extract the ZIP file and open the `david_frontend_application` folder in VS Code.
2. Open `index.html` in a browser, or install the VS Code **Live Server** extension and choose **Open with Live Server**.
3. Edit the text in `index.html`, colours and layout in `styles.css`, and menu behaviour in `script.js`.
4. Illustrations are local SVG files in `assets/` and can be edited or replaced with your own images.

## Publishing for free
Create a GitHub repository, upload the contents of this folder, and enable GitHub Pages in repository Settings → Pages. Alternatively, deploy the folder to Netlify.
